Ask your data in plain English

Hiver · 2026

Traces answers questions in natural language from live data, with the guardrails built into the database itself.

Governedevery answer stays within what your role is allowed to see

Most data questions are small

How many accounts used this feature last month. Which plan is this customer on. They don’t need a dashboard, and they shouldn’t sit in a queue waiting for an analyst either.

I’d built one of these at HackerRank already (SQLUp). Traces is the Hiver version.

How a question becomes an answer

Traces connects straight to the backend data: Amplitude for clickstream and HubSpot for CRM.

Before it writes any SQL, it reads an instruction file. It’s a Markdown handbook of business rules: what each table means, how to read it, and how to query it properly.

It builds the SQL from those rules and runs it.

Then an analytics agent reads what came back and answers the question that was actually asked.

How Traces answers a question

  1. A question in plain English"Which accounts on the Pro plan used the AI features last month?"
  2. Backend dataAmplitude for clickstream, HubSpot for CRM
  3. The handbookA Markdown file of business rules: what each table means and how to query it
  4. SQL, built and runWritten from those rules, run on a read-only connection
  5. Analytics agentReads the result and answers the question that was asked

The example question is made up.

The guardrails live in the database

It only has read-only access. It can look at anything it’s allowed to, and it can’t change a thing.

PII is masked at the database level by default, so personal data is already hidden before any result comes back.

Row limits are set sensibly. It’s for answering questions in plain English. Massive reports still come to an analyst.

Where the guardrails sit

  1. Read-only accessIt can look. It can't change a thing.
  2. PII masked in the databaseMasked by default, before any query result leaves it
  3. Sensible row limitsBuilt for answering questions. Exporting whole tables still goes through an analyst

Reaching data behind the VPN

Hiver’s internal BI sits behind a VPN. I built a proxy-based integration so MCP clients could query customer usage data in natural language without opening that up.

The proxy is the only way in, and the access rules sit on it.
